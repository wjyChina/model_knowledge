训练与参数范围：ControlNet 常冻结原 U-Net，只训练复制/旁路分支与 zero-conv，使控制从接近零逐步学会影响原模型；不同控制类型（canny / depth / pose / tile …）需要各自的训练数据与 checkpoint，不能互换。LoRA 可以挂在 ControlNet branch 或 base U-Net，但二者表达能力和风险不同。

环节数据 / 输入可训练模块冻结模块验收方法
ControlNet 训练(control map, target image) 严格配对；control map 由与推理一致的 preprocessor 生成复制的编码器分支 + zero-convbase U-Net、VAE、文本编码器控制保真度（边缘 / 深度 / 姿态对齐）、提示遵循、未配对 control map 的鲁棒性
在 ControlNet 上再挂 LoRA同上，外加风格 / 主体数据control branch 的 attention 投影base U-Net 与 control branch 主干控制不变性：换 control map 后风格仍生效
把 LoRA 挂到 base U-Net普通图文对，训练时不一定要 control mapbase U-Net attention / MLPVAE、文本编码器、control branch与使用同一 control map 的 ControlNet 组合是否互相干扰

论文依据：Adding Conditional Control to Text-to-Image Diffusion Models（ControlNet, arXiv:2302.05543）说明复制编码器、zero-conv 与多尺度注入的设计与训练目标；论文只覆盖 SD 系 U-Net 的注入方式，DiT / 视频模型的控制方案（如 block 级 residual、额外 token、adapter）不在该论文结论范围内，必须读对应实现。

参考图越强不一定越好：主体一致性、prompt 遵循和构图自由度互相竞争。评估时要用不同背景、角度和无关 prompt，避免只测一张相似图片。论文依据：IP-Adapter: Text Compatible Image Prompt Adapter（arXiv:2308.06721）说明解耦 cross-attention 与图像 prompt 与文本 prompt 的加权方式；该论文面向 SD 系 U-Net，迁移到 DiT 主干时必须核对实际实现（例如 SD3 的 Diffusers 实现把 image embeds 通过 image_proj 转成 hidden states 与 temb 后放入 joint_attention_kwargs，注入方式与 U-Net 版不同）。

5. 超分与修复：不要把生成细节当作真实恢复

类型输入输出内部常见结构
pixel SR低清 RGB [B,3,h,w]高分 RGB [B,3,H,W]卷积/Transformer residual blocks + upsampler
latent upscale低分 latent高分 latent扩散/flow 主干在更大 latent 网格生成
face restoration人脸 crop修复 crop识别先验 + 生成先验 + 融合
denoise/deblur带噪/模糊 RGBclean RGB条件重建网络或扩散反演

超分模型学习的是训练分布中“合理的高频细节”，不保证还原拍摄时真实存在的细节。文字、脸和医学/法证场景必须保留原图对照并明确生成性质。

工作流骨架
低清图 → resize/normalize → SR 模型 → 伪影检查
      → 必要时局部重绘 → 与原图对照 → 导出/标注
